# Changelog

All notable changes to this project are documented in this file. Versioning
follows [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-08-14

### Added

- Policy-driven AJL circuit compilation through four logical compiler levels.
- Trace- and plat-closure Jones evaluation with deterministic statevector and
  finite-shot modes.
- Logical circuit resource reporting, scheduling policies, and optional
  Clifford+T synthesis.
- Dense small-instance reference evaluation and a comprehensive test suite.
